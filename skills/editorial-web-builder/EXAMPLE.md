# Example: neighborhood studio visit note

This fictional example demonstrates the workflow. Its names, details, and copy are samples, not claims to reuse in a real project.

## Brief

A neighborhood service studio needs a mobile-first web record that customers can open from a printed QR card after a visit. The page should feel calm, personal, and credible while making the next care step easy to find.

Primary audience: the customer who just completed a visit.

Primary action: understand what happened and save the next recommendation.

## Visual contract

| Decision | Example answer |
| --- | --- |
| Emotional tone | A useful note left by a thoughtful professional |
| Base | Soft cream with visible paper warmth |
| Primary | Muted blue for identity, links, and emphasis |
| Ink | Deep slate rather than pure black |
| Accent | None; warmth comes from photography and copy |
| Display | Manrope SemiBold 600 |
| Expressive moment | One Instrument Serif Italic 400 line in the opening |
| Korean body | Pretendard |
| Image rule | Close, candid flash photography with natural texture |
| Repeated motif | Thin ruled lines that organize both print and web records |
| Avoid | Rounded card stack, decorative pills, pastel color mixing |

## Mobile composition

1. **Identity strip** — mark, visit date, and a compact “sample record” disclosure.
2. **Opening** — customer or subject name in Manrope; one short italic English phrase as the only expressive serif moment.
3. **Visit photograph** — approved candid image cropped to the same vertical rhythm as the print card.
4. **What we noticed** — one factual paragraph in a flat, ruled section.
5. **What we did** — a chronological list without floating cards.
6. **At home** — two clear next steps and a warning only if supported by professional guidance.
7. **Details** — provider, services, time, and contact in compact rows.
8. **Next action** — save, share, or book; only real actions appear as controls.

On desktop, the photograph and visit summary can share an asymmetric two-column frame while preserving the same source order.

## Sample copy

The following is fictional and exists only to demonstrate tone:

> 드라이 소리에 몸이 잠시 굳어 풍량을 낮추고 두 번 쉬어 갔습니다. 얼굴 주변은 가위 소리에 더 편안해해 클리퍼 대신 가위로 정리했습니다. 오늘 저녁에는 귀 주변이 완전히 마른 상태인지 한 번만 살펴봐 주세요.

Why it works:

- it describes observable behavior;
- it explains the professional response;
- it gives one practical next step;
- it does not claim a diagnosis or promise an outcome.

## Approval sequence

1. Present the visual contract, opening screen, and one information section.
2. Confirm palette, type, density, and photo treatment.
3. Approve one identity application and one generated or commissioned image before producing the full family.
4. Implement the complete static page after direction approval.
5. Review the hosted preview and replace all fictional details with supplied truth.
6. Confirm whether the record is public, token-accessed, expiring, or private.
7. Publish only after the audience is approved.
8. Generate and decode-test QR exports from the final production URL.

## Example handoff note

- The web record uses one muted-blue identity color, a cream base, and documentary imagery for warmth.
- Manrope 600 carries display and data; Pretendard carries Korean; Instrument Serif Italic appears once in the opening.
- Printed and digital records share the same ruled-line motif.
- Customer-specific records should use opaque URLs and contain only the minimum necessary personal detail.
- QR files should include branded SVG/PNG plus a black-and-white fallback, both tested from the production URL.
